## 💾 Implementation Details

### Color Scheme
- **Summary**: Linear gradient, 135° angle
  - Start: `#1e3c72` (Professional dark blue)
  - End: `#2a5298` (Medium blue)
  
- **Referral**: Linear gradient, 135° angle
  - Start: `#d946a6` (Vibrant pink)
  - Mid: `#ec4899` (Hot pink)
  - End: `#f43f5e` (Deep red)

### Typography
- **Text color**: `white` at 95% opacity
- **Headers**: Font weight 700
- **Panels**: Semi-transparent at 15% opacity
- **Borders**: White at 20% opacity

### Data Processing
- Extracts clinical events from database
- Groups by section/category
- Identifies abnormal values
- Generates specific recommendations
- Calculates data-driven risk levels
